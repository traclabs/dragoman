## VIPER Lunar Rover Model

The VIPER (Volatiles Investigating Polar Exploration Rover) model used in `demos/viper/scene/` was derived from URDF files created as part of:

**Challenge:** NASA Space ROS Sim Summer Sprint Challenge  
**Team Lead:** @RBinson  
**Submission Title:** Lunar Pole Exploration Rover & Plugins  
**License:** Apache License 2.0 (see [licenses/vipermodel.txt](licenses/vipermodel.txt))  
**Submission:** https://github.com/space-ros/demos/pull/43  
**Source Repository:** https://github.com/RBinsonB/simulation/tree/feat/lunar_pole_exploration_rover/models/lunar_pole_exploration_rover

This model was generated as a submission to the NASA Space ROS Challenge and has been converted to USD format for use in Isaac Sim within this project.

## Lunar Environment

The lunar environment used in `demos/viper/scene/` was generated using **OmniLRS** (https://github.com/OmniLRS/OmniLRS), a tool for creating realistic lunar environments. The environment has been exported to USD format and is used as-is in this project.

**License:** BSD-3-Clause (see [licenses/omnilrs.txt](licenses/omnilrs.txt))
